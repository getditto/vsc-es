# Ditto Edge Studio v0.96.1

- The extension overview now puts capabilities, platform requirements, and limits
  up front, with three steps to get connected.
- This version is the first Open VSX test candidate. The publishing workflow
  verifies all four platform packages from the GitHub Release before upload.
- The extension uses the `DittoLive` publisher ID for Visual Studio Marketplace.

## Installation

Choose the VSIX for macOS (Apple silicon), Linux (x64 or arm64), or Windows
(x64). Follow the [installation guide](https://github.com/getditto/vsc-es#installation)
to install it and connect to Ditto.

VS Code treats `DittoLive.ditto-vsce` as a separate extension from
`ditto.ditto-vsce`. If you used an earlier build, keep it available to access
its local data and register your connections again in the new extension.
