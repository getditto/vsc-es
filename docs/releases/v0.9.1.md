# Ditto Edge Studio v0.9.1

**0.9.1 is a private engineering preview.** This patch release builds on the
0.9.0 diagnostics release with a much more capable Presence Graph and fixes
Server-mode connections after the Ditto Portal URL format changed to include
the `https://` scheme. It is published as a GitHub Release for internal
evaluation and is not published to the VS Code Marketplace.

## Highlights from 0.9.0

- **Debug Console** — connect directly to a running Ditto SDK 5.1+ app over its
  `debug_socket` and run live DQL without configuring a separate extension-side
  Ditto connection.
- **System metrics dashboard** — Database Metrics polls SDK 5.1's
  `system:metrics` virtual collection while visible and accumulates network,
  SQLite, and recovery counters since connect.
- **ADVISE in Query Editor** — inspect index recommendations, including the
  reason and ready-to-run `CREATE INDEX` statement.
- **5.1 replication/recovery log patterns** — Log Analyzer recognizes metadata
  corruption recovery, consecutive resets, local-trigger resets, and frequent
  post-eviction cleanup with recommendations.

## What's new in 0.9.1

### Presence Graph

- Full-mesh mode now distributes BFS layers across progressively larger,
  evenly spaced rings so large meshes remain readable beyond 100 devices.
- Selecting a node in indirect mode opens a focused view showing that node and
  its direct neighbors while dimming and blurring the rest of the mesh.
- Focus mode automatically fits the selected neighborhood in the viewport,
  and zoom controls now operate on the focused nodes rather than only the
  background mesh.
- Ring layout accounts for measured device-name pill widths so long names do
  not overlap each other or the selected node.
- Direct-mode transitions refit zoom when necessary, and renamed devices
  trigger a fresh layout.
- The Presence header and sync controls use a compact single-row layout to
  leave more room for the graph.
- Background gradient and animated stars are now disabled by default for a
  lighter, more responsive graph. They remain available through the graph
  effects toggle.
- Multicast connections are rendered alongside Bluetooth, LAN, P2P Wi-Fi,
  WebSocket, and Cloud connection types.

### Server connections

- Server connection URLs copied from the Ditto Portal can now be pasted
  directly into the connection editor, including absolute `http://` and
  `https://` URLs.
- Existing connections that stored only a host name are upgraded to
  `https://` before the SDK connects.
- Unsafe or malformed URL forms are rejected with actionable validation
  errors.

## Known issues

- The Debug Console remains available only on macOS and Linux because it uses
  Unix-domain sockets.
- `system:metrics` is startup-gated. If
  `dittoVsce.collectSystemMetrics` is changed, reconnect the database so the
  SDK opens with the new setting.
- The Presence Graph has not been manually validated with every supported
  platform at more than 100 live devices; the automated layout and rendering
  coverage is included in this release.
