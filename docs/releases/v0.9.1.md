# Ditto Edge Studio v0.9.1

This patch release fixes Server-mode connections after the Ditto Portal URL
format changed to include the `https://` scheme.

## Highlights

- Server connection URLs copied from the Ditto Portal can now be pasted
  directly into the connection editor.
- Existing connections that stored only a host name are upgraded automatically
  before the SDK connects.

## Changes

- Accepts absolute `http://` and `https://` Server URLs.
- Preserves compatibility with legacy host-only Server URLs by normalizing them
  to `https://` for the SDK.
- Adds regression coverage for Portal URLs, legacy connection migration, and
  unsafe URL forms.

## Known issues

- The Debug Console remains available only on macOS and Linux because it uses
  Unix-domain sockets.
