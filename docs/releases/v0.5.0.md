## Highlights
- First public build of Ditto Edge Studio for VS Code, Cursor, and Google Antigravity.
- Per-platform `.vsix` packages for macOS (Apple silicon), Linux (x64 + arm64), and Windows (x64).
- Manual-trigger CI for build, load, and end-to-end validation.

## Changes
- POC feature set ships: connection registration, peer presence view, ad-hoc DQL queries, sync subscription editor, attachment inspector.
- Cross-platform build + release pipeline established (`build-and-validate.yml` + `release.yml`).
- Bumped Node runtime requirement to 22 LTS.
- Terminology updated to current Ditto Portal vocabulary (Database ID / Development Token / URL).

## Known issues
- Intel Mac (`darwin-x64`) and Windows on ARM (`win32-arm64`) are not supported — the `@dittolive/ditto` SDK does not ship binaries for these targets.
- Pre-release tag suffixes (`-rc`, `-beta`) are not yet supported by the release workflow.
- The Antigravity CLI binary name varies by build (`agy` on current docs; some Linux builds use `antigravity`) — see [Antigravity docs](https://antigravity.google/docs/command).
