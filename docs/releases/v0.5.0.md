**0.5.0 is a private engineering preview.** It is not published to the VS Code Marketplace and will not auto-update. We're sharing it inside Ditto so engineers can try it out and give us feedback before any public release.

If you're a Ditto engineer reading this — please install it, use it against an app you actually work with, and tell us what's broken, missing, or confusing. We'd rather hear about it now than after we ship publicly.

## Highlights

Ditto Edge Studio is a VS Code-family extension for working with Ditto databases directly from your editor. It mirrors the SwiftUI Edge Studio app but lives in VS Code, Cursor, and Google Antigravity.

What ships in 0.5.0:

- **Register connections** to any Ditto Cloud app — paste a Database ID, Development Token, URL, and Websocket URL from the Portal and you're connected.
- **Peer presence view** — see who's connected to your local Ditto instance and the connection types being used (WebSocket, P2P Wi-Fi, LAN, Bluetooth, AWDL).
- **DQL Query Editor** — run ad-hoc queries with table and JSON result views, plus persistent query history and favorites.
- **Subscription editor** — register and manage sync subscriptions live.
- **Attachment inspector** — fetch and view documents that carry file attachments.
- **Per-platform builds** for macOS (Apple silicon), Linux (x86_64 + ARM64), and Windows (x86_64).

## Installing locally

Side-load the `.vsix` for your platform — there is **no Marketplace install**, no auto-update.

1. Scroll down to **Assets** at the bottom of this release page and download the `.vsix` matching your platform:

   | Platform              | Asset                                  |
   | --------------------- | -------------------------------------- |
   | macOS (Apple silicon) | `ditto-vsce-darwin-arm64-0.5.0.vsix`   |
   | Linux (x86_64)        | `ditto-vsce-linux-x64-0.5.0.vsix`      |
   | Linux (ARM64)         | `ditto-vsce-linux-arm64-0.5.0.vsix`    |
   | Windows (x86_64)      | `ditto-vsce-win32-x64-0.5.0.vsix`      |

2. Install in your editor — UI path is the same in all three editors (Extensions sidebar → `…` → **Install from VSIX…** → pick the downloaded file). CLI path differs by editor:

   ```bash
   # VS Code
   code --install-extension ~/Downloads/ditto-vsce-darwin-arm64-0.5.0.vsix

   # Cursor
   cursor --install-extension ~/Downloads/ditto-vsce-darwin-arm64-0.5.0.vsix

   # Google Antigravity (binary may also be `antigravity` on some builds)
   agy --install-extension ~/Downloads/ditto-vsce-darwin-arm64-0.5.0.vsix
   ```

3. Reload your editor (Command Palette → **Developer: Reload Window**). The Ditto icon appears in the activity bar — click it and the Welcome view walks you through registering your first connection.

The full guide, including the "Not supported" platforms, is in the [README Installation section](https://github.com/getditto/vsc-es#installation).

## Known issues

- **Intel Mac (`darwin-x64`) and Windows on ARM (`win32-arm64`) are not supported** — the `@dittolive/ditto` SDK does not ship binaries for those targets.
- **Antigravity CLI binary name varies by build** — `agy` on current Google docs, some Linux builds report `antigravity`. See the [Antigravity docs](https://antigravity.google/docs/command) if the command isn't found.
- **No SQLCipher** in this build — Ditto's local store is unencrypted at rest. Avoid pointing it at a Ditto app whose collections contain real customer data.
- **Pre-release tag suffixes** (`-rc`, `-beta`) are not yet supported by the release workflow — only `v<MAJOR>.<MINOR>.<PATCH>` tags produce releases.
- **No auto-update** — when 0.6.0 lands, you'll need to install it the same way (download `.vsix`, `--install-extension`).
