# v0.9.5 adversarial review — consolidated record (2026-09-07)

Two independent adversarial review rounds were run against the v0.9.5 release
branch (`release095-fixes`, PR #31) before tagging. This file is the durable
record: every finding, its cross-reviewer agreement, the verdict, and the
verification evidence. It exists so future reviewers don't re-litigate
settled items and so deferred items carry their rationale.

**Method.** Each round ran a panel of independent reviewers with adversarial
lenses (security, lifecycle/reliability, contract/manifest,
correctness/edge-cases, test-integrity, docs/release-readiness). A finding
was fixed **only when at least two reviewers independently agreed** on the
same underlying defect (or a CI gate corroborated one reviewer). Every acted
finding was additionally re-verified in code by the orchestrator before
any edit, and each fix ships with a regression test.

Round 1 predates the MCP merge into the release branch; round 2 covered the
full PR (~80 files, +7.5k lines) including the embedded MCP server and the
then-uncommitted MCP hardening (DNS-rebinding guard, session lifecycle,
controller serialization, `watch_query` abort wiring).

## Areas reviewers verified clean (round 2)

- **MCP security posture on the main path:** DNS-rebinding allowlist is
  exact-match incl. port and `[::1]` bracket form; no CORS headers
  anywhere; state-changing endpoints require JSON bodies and/or the session
  header (browser CSRF impossible); session ids are server-minted
  CSPRNG UUIDs; 4 MiB request cap enforced pre-read and during streaming;
  unknown/expired sessions are 404 **before** tool dispatch on both
  transports; the per-connection `mcpServerEnabled` gate holds on every
  start path incl. connect/switch/disconnect and mid-bind flips.
- **Credentials:** only in `SecretStorage`; write-time log redaction
  (Bearer forms, JSON keys, URL params, registered values); MCP tool output
  carries metadata flags only; `ditto://peers` strips metadata bodies on
  all three peer shapes.
- **DQL:** every interpolated identifier goes through
  `quoteIdentifier`/`quoteFieldPath` (backtick-doubling); composite index
  field order preserved end-to-end; same-name/different-definition index
  refused via `system:indexes` pre-check.
- **Contracts:** all 39 commands ↔ handlers; message unions exhaustive;
  `mcpServerDefinitionProviders` id matches; `affectsConfiguration('dittoVsce.mcpServer')`
  prefix-match really catches `.port` (verified against real VS Code
  semantics); 31 tools × 6 resources registered, locked by the tools-manifest
  test; no dropped/duplicated contributions.
- **Lifecycle (round-2 hardening itself):** `enqueue` FIFO can never wedge;
  session-map drain + idempotent `onclose` break the `close()` recursion
  on both transports; `stopping` latch prevents late-`initialize` repopulation;
  `watch_query` honors pre-aborted/mid-watch cancellation and detaches its
  listener; SystemMetricsHub ref-counting sound; deactivate ordering
  bounded.
