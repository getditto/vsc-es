# Security Policy

## Reporting a Vulnerability

If you believe you've found a security vulnerability in this project, please
report it privately rather than opening a public issue.

**Email:** security@ditto.com

Please include as much of the following as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce, including any proof-of-concept code
- The affected version(s) or commit
- Any known mitigations

We'll acknowledge your report within **3 business days** and aim to provide
an initial assessment — including next steps and an expected timeline for a
fix — within **10 business days**. We ask that you give us a reasonable
opportunity to address the issue before any public disclosure.

## Supported Versions

Only the latest released version of this extension is supported with
security updates. We recommend always running the most recent version
available on the Visual Studio Marketplace.
